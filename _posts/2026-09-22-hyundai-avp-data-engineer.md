## 원문

우리 조직은 스마트 기술을 활용하여 통합 모빌리티 서비스(MaaS) 솔루션인 셔클 플랫폼 개발과 운영 및 사업 업무를 수행합니다. 커뮤니티 기반 수요 응답 교통 서비스 '셔클'의 기획, 개발, 데이터 분석, 서비스 운영 및 사업 개발까지 모든 업무를 직접 수행하며, 고객과 서비스에 초점을 맞춰 기민하게 일합니다. MaaS라는 추상적인 개념을 체감할 수 있는 서비스로 만들어 모두의 자유로운 일상 이동을 실현하는 업무를 수행합니다. 셔클(https://www.shucle.com)은 2020년 AI 기술을 활용한 도심 수요 응답 교통으로 국내 최초 선보인 이래 가장 많은 이용자와 운행 기록을 보유한 No1. 커뮤니티 모빌리티 서비스 플랫폼입니다.

• 서비스에서 발생하는 다양한 이벤트를 데이터로 표현하는 과정에서 발생하는 문제를 소프트웨어 엔지니어링을 통해 해결
• 데이터를 통해 사용자를 이해하는 과정에서 생기는 기술적인 문제를 해결하고 데이터 플랫폼을 통해 데이터 기반의 의사결정을 지원하는 제품 개발 업무 수행
• 고가용성 및 확장에 용이한 데이터 처리 시스템 설계
• 다양한 형태의 정형/비정형 데이터를 안정적으로 수집할 수 있는 데이터 레이크하우스 아키텍처 고도화
• 데이터 사이언티스트의 모델 개발 생산성 향상을 위한 Feature Store 설계 및 구축
• 데이터 기반의 의사결정을 지원하는 데이터 제품 개발 및 지속 개선
• 실시간 및 배치 데이터 처리를 위한 안정적인 파이프라인 개발
• 데이터 정합성 검증 및 장애 대응이 용이한 테스트 가능한 파이프라인 환경 구축
• 서비스 요구사항에 따른 신속하고 정확한 데이터 제공 프로세스 최적화
• 데이터 표준화 정책 수립 및 데이터 사전 고도화
• 데이터 라이프사이클 관리 및 데이터 리니지 시스템 고도화
• 데이터 품질 모니터링 지표 설정 및 지속적인 품질 개선 활동 수행

• 학사 이상의 학위를 보유하신 분
• 3년 이상의 데이터 엔지니어 경력을 보유하신 분
• 대규모 트래픽 처리를 위한 확장 가능한 데이터 아키텍

## 공고 요약

현대자동차그룹의 모빌리티 서비스 플랫폼 '셔클'을 운영하는 팀에서 데이터 엔지니어를 채용합니다. 실시간 및 배치 데이터 파이프라인 개발, 데이터 레이크하우스 아키텍처 고도화, Feature Store 구축 등 데이터 플랫폼 전반을 담당합니다. 데이터 품질 모니터링, 데이터 리니지 시스템, 표준화 정책 수립 등 데이터 거버넌스 업무도 포함됩니다. 대규모 트래픽 환경에서 확장 가능한 데이터 시스템을 설계하고 데이터 기반 의사결정을 지원하는 제품을 개발하는 역할입니다.
