## 원문

에프앤엘코퍼레이션은 혁신적인 시장침투 전략을 통해 빠르게 성장하면서도, 고객중심적 사고로 지속가능한 브랜드를 만들어가는 회사입니다. 
외부 기관투자 없이 창립 4년 만에 연매출 400억을 달성했으며, 2025년에는 730억 규모로 고속 성장세를 이어나갔습니다.
이제는 한국을 대표할 Global Health & Beauty 브랜드로의 도약을 함께 할 인재를 기다리고 있습니다!

• 사내 AI Agent 플랫폼 설계 및 개발 (LLM 호출, 도구 연동, 근거 제시, 검토 단계 포함)
• 외부 채널 데이터 파이프라인 설계와 운영 (Amazon, TikTok Shop, 자사몰, 광고 플랫폼)
• BigQuery 내 Medallion 아키텍처 기반 데이터 모델링 및 품질 검증
• LLM 기반 업무 자동화 (실적 리포팅, 인사이트 추출, 경쟁사 모니터링)
• 사내 운영 대시보드 및 업무 도구 개발

• Python 또는 Node.js/TypeScript 기반 서비스 개발 및 운영 3년 이상 경험
• SQL 활용 능력 및 Data Warehouse 기반 업무 경험
• 클라우드 환경(GCP, AWS, Azure) 배포 및 운영 경험
• 외부 API 연동 및 ETL 파이프라인 구축 경험
• LLM API를 실제 제품 또는 업무에 적용해본 경험
• AI 코딩 도구(Claude Code, Codex, Cursor, Copilot 등) 실무 활용 경험 및 결과물을 검증하고 책임질 수 있는 역량

• AI 코딩 에이전트(Claude Code, Codex)를 활용한 개발, 리팩터링, 코드 리뷰
• MCP(Model Context Protocol) 서버 개발 또는 연동 경험
• 조직 내 AI 도구 도입 및 확산 주도 경험
• LLM 애플리케이션 개발 경험 (RAG, Agent, Tool Use)
• 이커머스 또는 광고 데이터 처리 경험
• GCP BigQuery, dbt, Airflow 등 데이터 스택 활용 경험
• React 기반 프론트엔드 개발 가능자
