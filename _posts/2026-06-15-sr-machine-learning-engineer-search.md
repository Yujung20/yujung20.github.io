## 원문

인포시즈는 제조·반도체·플랜트·금융 등 다양한 산업의 데이터를 AI가 실제 운영과 의사결정에 활용할 수 있는 구조로 연결하는 Enterprise AI Infrastructure 기업입니다.

현실의 산업 데이터는 단순한 텍스트가 아닙니다. 문서, 도면, 운영 이력, 매뉴얼, 로그, 시스템 데이터는 서로 복잡하게 연결되어 있으며,
AI가 실제로 활용하기 위해서는 이러한 정보를 정확하게 이해하고 연결할 수 있어야 합니다.

Machine Learning Engineer (Search)는 문서 검색 및 Parser 시스템을 고도화하고, LLM 기반 Retrieval 시스템과 Axiom 아키텍처를 실제 운영 환경까지 연결하는 역할을 맡게 됩니다.

단순히 검색 정확도를 높이는 역할이 아닙니다. 복잡한 산업 데이터를 어떻게 이해하고 연결할 것인지 고민하며,
실제 현장에서 신뢰할 수 있는 AI 검색 시스템을 만드는 역할에 가깝습니다.

이런 분을 찾고 있습니다
• 문제를 대충 넘기지 않고 끝까지 파고드는 분
• 단순 benchmark보다 실제 검색 품질과 운영 문제 해결에 더 관심이 있는 분
• 복잡한 문서와 데이터를 구조화하고 연결하는 문제를 좋아하는 분
• 논문 구현을 넘어 실제 운영 환경까지 연결하는 데 흥미가 있는 분
• 정답이 없는 문제를 스스로 정의하고 방향을 만들어갈 수 있는 분
• 어렵고 복잡한 문제를 해결하는 과정 자체를 즐기는 분
• AI가 산업의 운영 방식을 근본적으로 바꾸게 될 것이라 믿는 분

• 문서 검색(Retrieval) 시스템 고도화
• Document Parser 구조 설계 및 성능 개선
• Axiom 아키텍처 설계 및 개발

• 실제 운영 환경 적용을 위한 모델 및 시스템 최적화

• 2년 이상의 머신러닝 연구 경험 (석/박사 과정 포함)
