## 원문

골든플래닛은 구글(Google)과 세일즈포스(Salesforce)의 강력한 파트너로서, 글로벌 빅테크 기술을 기반으로 기업에 필요한 데이터 솔루션을 제공하는 IT 기업입니다.

ㆍ골든플래닛은 구글 프리미어 파트너사로, B2B 데이터 분석 SaaS를 만들고 있습니다.
ㆍSQL을 모르는 마케터나 기획자도 자연어로 질문하면, LLM 에이전트가 GA4 데이터가 적재된 BigQuery에서 
   자동으로 SQL을 생성, 실행하여 인사이트 리포트까지 제공하는 솔루션입니다.
ㆍLangGraph 기반의 복잡한 추론 워크플로우와 GCP 기반의 확장성 있는 아키텍처를 다루며, 현재 서비스를 시작으로 
   다양한 도메인의 AI 에이전트 서비스로 확장을 주도적으로 고민하고 함께 만들어갈 핵심 멤버를 찾습니다.

1. AI Agent Backend 개발 
• LangGraph 를 활용한 워크플로우 설계 
• 툴콜링, KV캐싱, 전체 하네스 세팅을 고려한 에이전틱 제품 개발 
• 컨텍스트 엔지니어링, 프롬프트 엔지니어링 설계 

2. 하네스 엔지니어링 응용 개발
• AI 코딩 도구(Claude Code) 를 활용한 하네스 엔지니어링으로 생산성 향상 및 검증
• Long Running Harness Agent 설계로 빠른 PoC 제작 

3. 백엔드 관리 
• 백엔드 환경 구축
• 운영 환경 트래픽 요청 대응 및 유지보수 진행
• MCP 서버 배포 및 관리

• 주도적으로 문제를 정의하고 해결하는 것을 즐기시는 분
• LangChain, LangGraph를 이용한 Agent 서비스 개발 경험이 있는 분
• LLM API 의 Native Function Calling 을 응용한 개발 경험(ReAct 패턴)이 있는 분 
• 프롬프트 엔지니어링 및 컨텍스트 엔지니어링을 통한 개발 경험이 있는 분
• 하네스를 고려한 Agent 서비스 개발이 가능한 분 
• Python 기반 백엔드 개발 경력 보유 또는 이에 준하는 역량을 보유하신 분 
• 백엔드를 위한 인프라 세팅(GCP,AWS,Azure)

## 공고 요약

골든플래닛은 구글 프리미어 파트너사로, 자연어 질문을 통해 BigQuery 데이터를 분석하는 B2B SaaS 솔루션을 개발하는 회사입니다. LangGraph 기반의 AI 에이전트 워크플로우를 설계하고 GCP 인프라 위에서 확장 가능한 백엔드를 구축할 핵심 개발자를 찾고 있습니다. 툴콜링, KV캐싱, 하네스 엔지니어링 등 에이전틱 제품 개발 전반을 담당하며, Claude Code 같은 AI 코딩 도구를 활용한 생산성 향상도 기대합니다. 단순 구현을 넘어 다양한 도메인으로 AI 에이전트 서비스를 확장하는 방향을 주도적으로 고민할 인재를 원합니다.
