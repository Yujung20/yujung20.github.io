## 원문

최근 금융위원회의 논의를 비롯해, 2028년부터 대규모 상장사를 시작으로 ESG 공시가 단계적으로 의무화됩니다. 이는 단순한 트렌드를 넘어 향후 수천 개의 기업이 필연적으로 마주해야 하는 거대한 B2B IT 솔루션 생태계가 열린다는 것을 의미합니다.
THE CSR은 지난 12년간 국내 1군 대기업들의 ESG 전략과 데이터를 다뤄온 전문 기업으로, B2B SaaS 솔루션인 'METAESG'를 직접 개발해 서비스하고 있습니다.
단순히 외부 클라이언트의 요구에 맞춰 코딩만 하는 외주 방식이 아닌, 사내 독립적인 프로덕트 팀에서 컨설턴트들의 도메인 지식과 방대한 비정형/정형 전문 데이터를 양분 삼아 진정한 AI 프로덕트를 만들어 갑니다.
“폭발적으로 성장하는 시장에서, 독보적인 데이터로 진짜 AI 프로덕트를 만듭니다”
THE CSR은 보안 기준을 충족한 정형/비정형 데이터를 기반으로, LLM API와 RAG 파이프라인을 실제 비즈니스 임팩트로 연결할 수 있는 최고의 환경을 갖추고 있으며, 본 채용을 통해 차세대 AI 엔진의 초기 아키텍처를 설계하고 구축하는 핵심 멤버(Founding Engineer)를 모시고자 합니다. 기존 백엔드/프론트엔드 팀원들과 협업하여 AI 파이프라인(RAG, FastAPI 연동 등)을 주도적으로 구축해 나가는 경험을 하실 수 있습니다.

• 팀 핏: 개발자가 주도적으로 프로덕트의 방향성을 설계하고 임팩트를 만들어내는 유기적인 원팀(One-team) 지향
• LLM 응답 품질 개선: LLM API 기반 프롬프트·컨텍스트 설계, 환각 제어, 응답 품질 개선
• RAG 파이프라인 고도화: 방대한 B2B 전문 문서(텍스트, 표, 수치 등)를 활용한 RAG 아키텍처를 점진적으로 개선하고 Vector DB 연동을 최적화. 검색 품질을 held-out 평가셋으로 측정하고 회귀를 관리
• API 백엔드 연동: FastAPI로 AI 생성 모듈을 안정적으로 서빙하고, 저장소·CI·리뷰를 거쳐 기존 시스템과 통합
• 일정 공유: 담당 범위의 WBS·개발 일정을

## 공고 요약

더씨에스알은 ESG 공시 의무화 시대를 대비한 B2B SaaS 플랫폼 'METAESG'를 운영하는 ESG 전문 기업으로, LLM·RAG 기반 AI 엔진을 초기부터 설계·구축할 핵심 엔지니어(Founding Engineer)를 채용합니다. 주요 업무는 LLM API 프롬프트 설계 및 응답 품질 개선, RAG 파이프라인 고도화, FastAPI를 통한 AI 모듈 서빙 및 기존 시스템 통합입니다. 12년간 축적된 ESG 도메인 전문 데이터를 활용하여 실질적인 비즈니스 임팩트를 만드는 AI 프로덕트 개발 환경을 제공합니다.
