## 원문

About the Team & Mission

Intelligence Data Platform 팀은 다양한 분야의 데이터를 연동, 가공, 정제하여 항상 최신의 의미있고 체계화된 형태로 데이터를 유지하는 데이터 플랫폼을 개발하고 운영하며, 데이터를 안정적으로 서빙하여 항상 최신의 정확한 정보가  답변에 사용 되도록 합니다.

Data Platform 또는 이에 기반한 Data Serving의 영역에서 강점을 가지고 초기 구조 설계부터 개발 운영 품질 개선까지 주도해 나갈 백엔드 엔지니어를 찾고 있습니다.

• 글로벌 데이터 연동 및 모델링: 날씨, 뉴스, 증권, 스포츠 등 다양한 도메인의 글로벌 데이터를 연동하고 데이터 특성에 맞게 모델링합니다.
• 데이터 파이프라인 개발 및 운영: 대용량 데이터의 시·공간을 고려한 분산 처리와 AI를 활용한 데이터 정규화·정제 등 고도화된 데이터 파이프라인을 구축하고 운영합니다.
• 대규모 데이터 서빙 및 API 운영: 대규모 트래픽과 글로벌 요청에 대해서도 가공된 데이터가 안정적으로 제공될 수 있도록 글로벌 대응 API 및 서빙 시스템을 개발하고 운영합니다.
• 품질 지표 관리 및 모니터링: 운영 로그를 지속적으로 모니터링하고, 자동화된 품질 지표를 생성하여 데이터 품질과 시스템 안정성을 끊임없이 개선합니다.
• 기술 리딩 및 시스템 개선: 팀 내 설계 리뷰와 기술 의사결정을 리딩하며, 직면한 복잡한 문제들을 재사용 가능하고 확장성 있는 시스템 개선으로 연결합니다.

• 백엔드 서비스 설계, 개발, 운영 경력 7년 이상이신 분
• Python, Java, Kotlin 중 하나 이상의 언어를 능숙하게 사용하시는 분
• Production traffic을 받는 API/backend service를 설계하고 운영해 보신 분
• 로그와 지표를 기반으로 서비스 혹은 데이터 문제의 원인을 분석하고 개선해 보신 분
• 초기 설계, 구조화, 표준화, 운영 안정성 개선을 주도해 보신 분

• Python pandas / spark 을 이용한
