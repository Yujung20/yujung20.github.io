## 원문

파수에이아이는 혁신적인 기술을 통해 고객의 비즈니스 가치를 극대화하는 것을 목표로 하는 선도적인 IT 기업입니다. 
1. 데이터 보안 및 관리 솔루션 분야에서의 전문성을 보유하고 있습니다. 
2. 고객 맞춤형 솔루션 제공을 통해 다양한 산업 분야에서 신뢰를 받고 있습니다. 
3. 지속적인 연구 개발을 통해 최신 기술 트렌드를 선도하고 있습니다. 

이번에 모집하는 직무는 OT/ICS 환경의 자산, 네트워크 및 보안 데이터를 통합 분석·가시화하는 기술 개발을 담당합니다. OT 네트워크에서 수집되는 다양한 산업용 프로토콜과 보안 솔루션 데이터를 분석하여 OT 자산 식별, 통신 현황, 취약점 및 보안 위협 정보를 통합적으로 제공하는 플랫폼을 개발하는 역량이 필요합니다. 

파수에이아이와 함께 미래를 만들어 나갈 열정적인 개발자분들의 많은 지원 바랍니다.

1. OT보안 플랫폼 개발
•	OT/ICS 자산 및 네트워크 가시화 기능 개발
•	OT 자산/통신/취약점/위협 데이터 수집 및 분석 기능 개발
•	대시보드 및 관리 기능 개발
•	대용량 데이터 검색 및 분석 기능 개발

2. OT/ICS 프로토콜 분석 및 파싱
•	산업용 네트워크 패킷 분석
•	OT/ICS 프로토콜 Parser 개발
•	프로토콜별 자산 및 통신정보 추출
•	신규 OT 프로토콜 분석 및 Parser 확장

3. OT보안 솔루션 연동 개발
•	OT 보안 솔루션 API 연동
•	API를 통한 Asset, Vulnerability, Communication, Alert 등의 데이터 수집

•	주기적인 데이터 동기화 및 상태 관리 기능 개발

4. 데이터 수집·검색 플랫폼 개발
•	OT 데이터 저장 및 검색
•	대용량 네트워크/자산 데이터 처리
•	REST API 개발
•	외부 보안 솔루션 및 시스템 연동
