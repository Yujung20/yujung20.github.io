## 원문

글로벌 투자기관이 선택한 맨데이터와 함께, 한국의 데이터를 세계 금융시장에 연결할 열정 있는 엔지니어를 찾습니다.
맨데이터 Data Team은 카드·POS·멤버십·이커머스 등 다양한 소비 데이터를 수집하고, 글로벌 기관투자자가 활용할 수 있는 투자 데이터셋으로 구조화합니다.
현재 AWS 기반 데이터 파이프라인을 고도화하며 기업·브랜드·상품 단위의 데이터 표준화, 품질 검증, 일별 데이터 전송 자동화, 고객용 API 개발을 진행하고 있습니다.
단순히 데이터를 적재하는 것을 넘어, 복잡한 원천 데이터를 신뢰도 높은 금융 데이터로 전환하고 글로벌 고객에게 안정적으로 제공하는 전 과정을 함께 설계할 데이터 엔지니어를 찾습니다.

데이터 파이프라인 구축 및 운영
• 카드·POS·멤버십 등 대용량 원천 데이터 수집 및 적재
• Python·SQL 기반 데이터 처리 파이프라인 개발
• AWS 기반 일별 배치 처리 및 자동화
• 데이터 누락·지연·실패 모니터링 및 복구 체계 구축
데이터 구조화 및 품질관리
• 서로 다른 원천 데이터 포맷의 표준화 및 정제
• 기업·브랜드·상품·SKU·티커 간 데이터 모델 설계
• 중복·결측·이상치·취소 거래 처리
• 정합성, 최신성, 스키마 변경 등 품질 검증 자동화
• 글로벌 기관투자자 기준에 맞춘 데이터 품질관리
데이터 제공 시스템 개발
• 글로벌 고객 대상 데이터 API 개발 및 운영
• AWS S3, SFTP, API 기반 일별 데이터 전송
• 고객별 스키마·컬럼·전송 방식 커스터마이징
• 데이터 접근 권한 및 배포 이력 관리
데이터 제품 고도화
• 신규 데이터 상품 및 섹터별 데이터셋 구축
• 백테스트 가능한 Point-in-Time 데이터 관리
• 반복적인 데이터 운영 업무 자동화
• 분석팀·제품팀·글로벌 고객과의 기술 협업 및 CX관리

• Python과 SQL을 활용한 데이터 처리 및 개발 역량
• 데이터 파이프라인 구축 또는 운영 경험
• AWS 환경에서 데이터 저장·처리·배포 경험
• 관계형 데이터베이스 및 데이터 모델링에

## 공고 요약

맨데이터는 카드·POS·멤버십 등 소비 데이터를 글로벌 기관투자자용 금융 데이터셋으로 변환하는 Data Engineer를 채용합니다. AWS 기반 배치 파이프라인 구축, 데이터 품질 검증 자동화, 고객용 API 개발 등 데이터의 수집부터 제공까지 전 과정을 담당합니다. 단순 적재를 넘어 신뢰도 높은 금융 데이터로 전환하고 글로벌 고객에게 안정적으로 서비스하는 역할을 수행합니다.
