## 원문

무인화연구소는 무인공간 AIoT 기술을 선도하는 기업으로, 앤딩스터디카페 48개 공간을 직원 없이 24시간 운영하며 공간 운영 OS(Space OS)를 개발해왔어요. 
1. 출입·예약·결제: 직원 없이 예약하고 결제하고 입장하는 흐름을 제공합니다. 
2. 공조: 쾌적함을 유지하면서 냉방 에너지를 줄이는 자동 운전 엔진을 개발합니다. 
3. 현장 제어: 매장 에어컨·센서·출입문(Matter, SmartThings)을 연결하는 엣지와 클라우드를 통해 공간을 세분화한 전문 에이전트를 만들고, 이들을 조율하는 오케스트레이션을 합니다. 
이제 무인화연구소와 함께 공간 운영 에이전트를 만들어갈 엔지니어를 찾고 있어요. 함께 혁신적인 공간 운영 솔루션을 만들어보세요!

• 에이전트 간 오케스트레이션: 역할 배정, 실행 순서·권한, 작업 상태(대기·재개·실패) 관리
• 기존 시스템 연동: 예약·출입 API, 공조 엔진, 점주·본사 플랫폼 데이터
• 현장 검증: 직영점과 실제 매장에서 에이전트 동작 확인, 로그 기반 개선
• 국내외 PoC 기술 대응: 파트너 공간에 맞춘 에이전트 구성과 데모

• TypeScript(Node.js) 백엔드 실무 3년 이상
• LLM 도구 호출(tool calling) 기반 에이전트 또는 워크플로우를 직접 구현해 운영한 경험
• PostgreSQL 스키마 설계 및 운영 경험
• 외부 API·기기 연동에서 실패·재시도·타임아웃을 설계해 본 경험
• Git 협업 및 코드 리뷰 문화에 익숙한 분

• 멀티 에이전트 오케스트레이션, 상태 머신, 작업 큐 설계 경험
• IoT·설비 제어 경험: Matter, Zigbee, SmartThings, Home Assistant 등
• 공조·에너지·빌딩 자동화 도메인 이해
• Python 데이터·제어 로직 읽기와 수정
• AWS(ECS Fargate, RDS, SQS) 운영, Sentry 기반 품질 관리

## 공고 요약

무인화연구소는 스터디카페 48개 매장을 무인으로 운영하는 공간 운영 OS(Space OS)를 개발하는 회사입니다. LLM 기반 AI 에이전트를 활용해 출입·예약·결제·공조·현장 제어를 자동화하는 시스템을 만들 엔지니어를 찾고 있습니다. TypeScript 백엔드 실력과 LLM tool calling 기반 에이전트 구현 경험이 핵심 요건이며, IoT 기기 연동 및 멀티 에이전트 오케스트레이션 경험자를 우대합니다. 실제 직영점에서 에이전트 동작을 검증하고 개선하는 현장 중심의 실무를 담당하게 됩니다.
