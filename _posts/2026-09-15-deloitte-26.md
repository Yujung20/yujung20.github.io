• 프로젝트 수행 시 보안, 거버넌스, 표준 아키텍처 기준 반영

• 데이터 엔지니어링, 데이터 플랫폼 구축 또는 데이터 아키텍처 설계 관련 실무 경력 5년 이상 12년 이하

• 클라우드 환경에서 데이터 파이프라인 또는 분석 플랫폼 구축 경험
• 데이터 모델링, 성능 최적화, 운영 안정화에 대한 이해

딜로이트 컨설팅에서 다양한 산업 고객을 대상으로 데이터 플랫폼 설계 및 구축을 담당할 시니어 데이터 엔지니어를 채용합니다. 단순 개발을 넘어 고객의 데이터 환경을 진단하고 클라우드 기반 데이터 레이크/웨어하우스 구축, ETL/ELT 파이프라인 개발, 실시간 데이터 처리 등 엔드투엔드 데이터 플랫폼을 구현하는 역할입니다. 특히 제조 산업군 프로젝트 경험이 필수이며, 기술 컨설팅 역량과 거버넌스·보안 기준 이해가 요구됩니다.
