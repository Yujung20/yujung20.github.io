## 원문

[우리를 소개해요]

Data Governance팀은 요기요의 각 서비스에서 생성되는 내부 데이터와 공공 데이터 등 다양한 원천 데이터를 분석·처리하여 데이터 플랫폼을 운영하며, 분석 및 서비스에 필요한 데이터를 적시에 안정적으로 제공할 수 있도록 노력합니다.

우리는 데이터를 통해 요기요 서비스의 성장을 견인하고, 모든 구성원이 데이터에 기반하여 더 나은 결정을 내릴 수 있도록 지원합니다. 안정적이고 확장 가능한 데이터 플랫폼을 통해 데이터 품질과 거버넌스를 확립하여 신뢰할 수 있는 데이터를 제공하고, 데이터 자산의 가치를 극대화합니다.


[이런 경험을 할 수 있어요]

• 요기요의 방대한 데이터를 수집·처리·저장하여 누구나 데이터로부터 비즈니스 가치를 창출할 수 있도록 지원하는 역할을 수행할 수 있어요.
• 최신 데이터 플랫폼 위에서 데이터 모델 및 데이터 파이프라인을 설계하고 개발하며, 안정적인 데이터 서비스를 제공할 수 있어요.
• 데이터에 대한 깊은 이해와 집요한 분석을 통해 논리적인 데이터 모델을 구축하고, 효과적인 데이터 처리 방안을 제시하며, 동료들과의 적극적인 소통을 통해 요기요의 Data Democratization을 이끌어갈 수 있어요.

[우리는 이런 일을 해요]

• 요기요의DW/DM을 설계, 구축, 운영하고 고도화합니다.
• 커머스, 머천트, 고객 행동 로그 등 요기요 전반의 데이터를 집계 및 가공하여 표준화된 데이터 모델을 구현합니다.
• 비즈니스 요구사항에 부합하는 확장 가능하고 효율적인 데이터 모델을 설계·구축합니다.
• 데이터 거버넌스 관리를 통해 전사 구성원의 데이터 접근성을 높이고, 데이터의 신뢰성과 일관성을 확보합니다.

## 공고 요약

요기요(위대한상상)의 Data Governance팀에서 5년 이상 경력의 데이터 엔지니어를 채용합니다. 주요 업무는 DW/DM 설계·구축·운영 및 고도화이며, 커머스·머천트·고객 행동 로그 등 다양한 데이터를 표준화된 데이터 모델로 구현하는 역할을 담당합니다. 비즈니스 요구사항에 맞는 확장 가능한 데이터 모델을 설계하고, 데이터 거버넌스를 통해 전사 데이터 신뢰성과 접근성을 높이는 것이 핵심 미션입니다. 안정적인 데이터 플랫폼 운영을 통해 전사 구성원의 데이터 기반 의사결정을 지원하는 Data Democratization을 지향합니다.
