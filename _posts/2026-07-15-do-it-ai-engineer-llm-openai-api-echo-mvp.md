## 원문

DO IT COMPANY는 AI 자기이해 플랫폼 ECHO(진짜 나를 찾아줘)를 개발하고 있습니다.

ECHO는 상담·진단·치료·매칭 서비스가 아닙니다. 사용자의 자유로운 경험 입력을 상황, 감정, 사실과 해석, 반복 패턴, 선택 기준으로 구조화하고, 사용자가 스스로를 더 정확히 이해하도록 돕는 AI 기반 서비스입니다. 관계는 여러 입력 데이터 중 하나이며, 서비스의 목적은 자기이해입니다.

현재 MVP는 B구조를 기반으로 하며, 사용자의 입력을 이해하고 확인·정정·기억한 뒤 다음 질문과 최종 리포트까지 연결하는 상태 기반 AI 시스템을 구현합니다. 핵심은 단순한 답변 생성이 아니라 기억, 이해 확인, 사용자 정정 반영, 동적 질문 생성, 상태 관리와 데이터 구조화입니다.

이번 포지션은 Next.js 15 모노레포, TypeScript, Supabase, PostgreSQL, OpenAI API 환경에서 ECHO의 AI 코어를 직접 구현하는 역할입니다. 사용자 입력 처리, 대화 상태 관리, 프롬프트 운영, 구조화 데이터 저장, 리포트 생성, 응답 품질 평가, 예외 처리와 안전 정책까지 AI 기능 전체를 담당합니다.

MVP 단계에서는 B구조의 자기이해 경험을 안정적으로 완성하고, 이후 축적된 행동·감정·선택 데이터를 A구조의 매칭·커뮤니티 확장 자산으로 전환할 수 있도록 처음부터 확장 가능한 구조로 개발합니다.

• Next.js 15 모노레포, TypeScript, Supabase, PostgreSQL, OpenAI API 기반으로 ECHO MVP의 AI 기능을 구현합니다.
• 사용자의 자유 입력을 상황, 감정, 사실과 해석, 반복 패턴, 선택 기준으로 구조화하는 처리 로직을 개발합니다.
• 사용자 입력에 대한 이해 확인, 사용자 정정 반영, 세션 기억, 동적 질문 생성과 상태 전이 로직을 구현합니다.
• 한 화면에 질문 1개가 제공되는 단계형 대화 흐름과 세션 상태를 안정적으로 관리합니다.
• OpenAI API 기반 프롬프트, 컨텍스트, 응답 형식, 재시
