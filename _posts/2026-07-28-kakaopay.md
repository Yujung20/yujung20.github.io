## 원문

카카오페이증권은 어렵고 복잡한 투자의 문턱을 낮추고,
생활 속 가장 가까운 금융투자 회사를 만듭니다.
국내최초 테크핀 증권사에서 새로운 투자문화를 함께 만들어 갈 여러분을 기다립니다.

조직소개
• 금융 서비스 성장에 따라 고객 데이터, 거래 데이터, 자산 데이터가 빠르게 증가하는 환경에서 이를 안정적으로 저장하고 활용할 수 있는 구조가 필요합니다.
• 고객자산, 계좌수익률, 투자리포트 등 고객에게 제공되는 데이터는 높은 정합성과 신뢰성이 필수적입니다.
• 원장 시스템에 집중되는 조회 트래픽과 지속적인 데이터 증가에 대응하기 위해 분산 데이터베이스 기반의 확장 가능한 구조가 필요합니다.
• 대규모 금융 데이터 플랫폼을 직접 설계하고 운영하며, 고객자산·수익률 등을 생산하는 플랫폼을 구축하는 경험을 할 수 있습니다.
• 데이터 생산 체계, 데이터 파이프라인, 운영 자동화, 데이터 제공 구조를 설계하는 플랫폼 엔지니어링 역량을 쌓을 수 있습니다.
• 분산 데이터베이스 기반의 데이터 모델링, 트래픽 분산, 조회 성능 최적화 등 일반 웹 서비스에서는 경험하기 어려운 도전 과제를 해결할 수 있습니다.
• 금융 데이터 플랫폼의 미래 아키텍처를 설계하며, 분산 데이터베이스와 데이터 파이프라인 기반의 고객 금융 데이터 플랫폼을 함께 구축할 엔지니어를 찾고 있습니다.
• 10가지 불가능한 이유보다 한 가지 가능한 해결책을 찾아 실행하며, 속도와 정확성의 균형을 잡는 엔지니어링 문화입니다.
• 코드와 프로그래밍보다 먼저 근본 원인과 문제 해결에 집중하고, 단순한 운영이 아닌 아키텍처 현대화를 주도하는 팀입니다.

• 금융 데이터 플랫폼의 장기적 아키텍처를 설계하고, 확장성·안정성·성능을 함께 고려한 기술 로드맵을 수립하며, 주요 기술 의사결정을 주도합니다.
• 분산 데이터베이스와 데이터 파이프라인 기반의 고객 금융 데이터 처리 시스템을 설계·구축하고, 데이터 정합성과 성능을 최적화하는 종합적인 전략을 수립하며 운영합니다.
• 대용량 데이터 처리 환경에서의 성능 문제, 데이터 정

## 공고 요약

카카오페이증권은 급증하는 금융 데이터를 안정적으로 처리할 대용량 데이터 플랫폼 시니어 백엔드 개발자를 채용합니다. 고객 자산, 계좌 수익률 등 정합성이 중요한 금융 데이터를 분산 데이터베이스 기반으로 설계·운영할 인재를 찾고 있습니다. 단순 운영이 아닌 아키텍처 현대화와 기술 로드맵 수립을 주도할 수 있는 역량이 필요합니다. 데이터 파이프라인, 트래픽 분산, 조회 성능 최적화 등 고난이도 엔지니어링 문제를 해결하는 환경입니다.
