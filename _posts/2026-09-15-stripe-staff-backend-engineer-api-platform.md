Stripe는 더블린에서 API 플랫폼을 담당할 Staff Backend Engineer를 채용합니다. 수백만 개의 기업이 사용하는 결제 인프라의 핵심인 API 시스템을 설계하고 확장하는 역할입니다. 대규모 트래픽 환경에서 낮은 레이턴시와 높은 안정성을 유지하는 시스템을 구축할 수 있는 시니어급 엔지니어를 찾고 있습니다. 복잡한 문제를 단순화하고, 인프라와 개발자 경험 모두에 깊은 관심을 가진 사람을 원합니다.
