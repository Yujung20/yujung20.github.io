## 원문

메디워크AI는 의료 AI 개발의 데이터 병목을 푸는 인프라 스타트업입니다. 
의료 AI를 학습·검증하려면 의사 수준의 임상 판단이 담긴 고품질 데이터라는 필요하지만 체계적인 데이터 구축 및 가공 기업이 국내에 존재하지 않습니다. 
저희는 AI 데이터 전문 상장사 크라우드웍스의 자회사 팀이 독립해 설립했고, 누적 48개 프로젝트·30만+ 데이터 처리 경험을 가진 팀이 의료 도메인에 본격 집중하고 있습니다.

25개 분과 1,200명 전문의가 사용하는 의료 데이터 라벨링·평가 플랫폼. 매일 수천 건의 의료 데이터가 들어오고, 전문의들이 라벨링·교차검증을 수행하고, 그 결과가 의료 AI 회사의 학습·평가에 쓰입니다. 백엔드 아키텍처 설계부터 전문의 작업 인터페이스, 그리고 QA 엔진(라벨 오류 예측 ML 시스템)의 백엔드 통합까지를 함께 만듭니다.

일반 SaaS와 달리 의료 전문가의 작업 패턴이 그대로 ML 학습 데이터가 되는 구조라, 백엔드 설계가 곧 ML 시스템 설계와 맞물립니다. 시장이 본격 개화하는 시점(2026 정부 의료 AI 직접 투자 2,478억)에서 핵심 인프라를 처음부터 만들 수 있습니다.

• 기존 데이터 가공 클라이언트 유지, 개선
• 진행 중 프로젝트에 맞는 UI 커스터마이징
• 백엔드 서버 운영, 유지보수 (배포, 모니터링, 장애 대응)
• 프로젝트 별 데이터 파이프라인 관리
• 오토 라벨링 기능 고도화 (사전 학습 모델 적용, 프로젝트 별 파인튜닝)
• 라벨링 품질 대시보드 개발 (진행률, 오류율, 작업자 성과)
• RLHF 평가 시스템 MVP 개발 (LLM 답변 비교, 순위, 코멘트)
• 합성 데이터 모델 학습 파이프라인 구축

• 백엔드 개발 경력 3년이상
• Spring Boot,FastAPI등 backend 개발경험
• JPA 등 ORM을 활용한 데이터 모델링 및 개발 경험
• REST API 설계 및 서비스 운영 경험
• React/Next.js 등 프론트엔드 프레임워크 사용 경험
• Docker 기반 개발 및 배포 환경에 대한

## 공고 요약

메디워크AI는 의료 AI 학습에 필요한 고품질 데이터 가공 플랫폼을 구축하는 스타트업으로, 1,200명 전문의가 사용하는 라벨링·평가 플랫폼의 풀스택 개발자를 모집합니다. 백엔드 아키텍처 설계부터 전문의 작업 인터페이스, QA 엔진 통합까지 전반을 담당하며, ML 파이프라인과 긴밀하게 연계된 시스템을 개발합니다. 오토 라벨링 고도화, RLHF 평가 시스템, 합성 데이터 파이프라인 등 AI 인프라 전반을 처음부터 설계·구축할 수 있는 포지션입니다.
