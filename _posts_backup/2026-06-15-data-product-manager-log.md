## 원문

[합류하게 될 팀에 대해 알려드려요]

• Data Product Manager(Log)는 Real-Time Data 팀에 속해 있어요.
• Real-Time Data 팀은 토스뱅크의 모든 제품이 신뢰할 수 있는 데이터를 기반으로 움직일 수 있도록, 로그 데이터의 '정의–수집–검증–활용 전 과정'을 설계하고 운영합니다.
• 앱 로그 매니저는 로그가 시간이 지나도 의미가 변하지 않고, 데이터로 신뢰받을 수 있도록 표준과 품질 기준을 설계하고 관리하는 역할을 합니다.

[합류하면 함께할 업무예요]

• 앱과 서버 전반의 로그 구조와 표준(json schema, key/value rule)을 정의하고 관리해요.
• 로그 정의서(Log Spec)를 구축하고, key/value의 생성·변경·삭제 이력을 추적 가능한 형태로 관리해요.
• FE·BE·Native 로그의 구조적 차이를 최소화하고, 통합적인 로그 표준 정책을 운영해요.
• 로그 데이터의 품질을 보장하기 위한 자동 검증(Validation) 시스템을 설계하고 개선해요.
     • Syntax 검증: 필드, 타입, 구조 점검
     • Semantic 검증: 동일 행동의 로그 일관성 및 의미 검증
• 표준화와 자동화 과정에서 팀별 리소스와 효율의 균형을 고려하며,전체 조직의 로그 운영 효율을 최적화하는 구조를 설계해요.
• 데이터 엔지니어, 데이터 애널리스트, 개발자와 협력해 로그 표준화와 QA 프로세스를 조직 전반에 내재화해요.
• 디자인 변경이나 다국어(i18n) 확장 등 UI/UX 변화가 로그 의미에 미치는 영향을 분석하고 대응해요.
• 표준화·검증·자동화의 균형을 설계하며, 전체 데이터 품질을 책임져요.

[이런 분과 함께하고 싶어요]

• 로그의 정의부터 검증까지 전 주기를 스스로 구조화할 수 있는 분  로그 정의서(Log Spec) 작성, 스키마 설계, key/value 관리 경험이 있다면 더욱 좋아요.
• 로그 품질 보장과 검증 자동화에 강한 문제의식을 가지고, 실제로 Validation/QA 시

## 공고 요약

토스뱅크 Real-Time Data 팀에서 앱/서버 로그 데이터의 전 주기(정의-수집-검증-활용)를 설계하고 운영할 Data Product Manager를 채용합니다. 로그 구조 표준화, 스키마 설계, 자동 검증 시스템 구축이 핵심 업무이며, 데이터 엔지니어·애널리스트·개발자와 긴밀히 협력하는 역할입니다. 로그 품질 보장과 검증 자동화에 강한 문제의식을 가진 분을 찾고 있으며, FE/BE/Native 로그의 통합 표준 정책 운영과 조직 전반의 로그 QA 프로세스 내재화를 담당합니다.

## 필수 지원 조건

- 로그 정의서(Log Spec) 작성 및 JSON Schema 기반 스키마 설계 경험
- key/value 생성·변경·삭제 이력 추적 및 로그 표준 관리 경험
- Syntax/Semantic 검증을 포함한 로그 Validation/QA 자동화 시스템 설계 경험
- 데이터 엔지니어, 개발자 등 다직군과의 협업을 통한 표준화 프로세스 운영 경험

## 추천 대상

- 로그 데이터 품질 관리와 검증 자동화에 깊은 관심을 가진 데이터 직군 종사자
- 앱/서버 로그 구조 설계 및 스키마 표준화 경험이 있는 분
- 개발자·데이터 팀 간 협업 경험이 풍부하고 기술적 커뮤니케이션에 능숙한 분
- UI/UX 변화나 다국어 확장이 데이터에 미치는 영향을 분석한 경험이 있는 분
